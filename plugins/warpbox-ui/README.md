# warpbox-ui — WARP во вкладке «Плагины»

Панельная часть WARP: плагин `splify2-extended-plugins`, GPL-3.0. Ядровая часть — плагин `warpbox` из репозитория steer
(вид `warp`, регистрация, подбор, хук `expand`); этот плагин требует его (`requires.plugins`) и ничего не делает с ядром сам.

**Почему два плагина, а не один.** SDK позволяет одному плагину нести и ядровую, и панельную часть, но `warpbox`
собирается и выпускается вместе с steer (он поставляется из семени ядра и обновляется с ним), а панель и её словари
живут в репозитории расширений и выходят в своём ритме. Разделение держит ядро без интерфейсного кода, а панель — без
привязки к выпуску ядра.

## Что даёт

| Где | Что |
|---|---|
| карточка плагина | выходы WARP: состояние, туннели (точка, колония, страна, задержка), число туннелей, выбор туннеля, протокол, страна, подбор точек, создание и удаление выхода; настройки «для новых выходов» |
| блок «Куда» правила (`outputKind.ruleTarget`) | выходы WARP пилюлями, правка ключей на месте |
| «Доска» (`boardTile`) | плитка: сколько туннелей работает |
| мастер первой настройки (`setupVia`) | ветка «WARP», доступна, пока стоит плагин `warpbox` |
| значки (`badge`) | MASQUE |

Состояние идёт из `status` (`status.outputs.<выход>.group.warp`), правки — через `host.core.edit` (спека), подбор точек —
методом `scan` (задание на роутере, итог — `scan_state`). Конфигов туннелей, регистраций Cloudflare и спеки на диске
плагин не читает: границу API держит `s2p lint --official`.

## Методы

| Метод | Что |
|---|---|
| `scan {group}` | запустить подбор точек входа (`steer warp-scan`), в фоне |
| `scan_state {group}` | идёт ли подбор, когда закончился, итог или причина неудачи |
| `defaults_get` / `defaults_set` | настройки «для новых выходов» (схема `settings.schema.json`) |

## Сборка и проверка

```sh
npm install --no-save @splify2/plugin-api preact vite typescript   # плагин-api — из plugin-sdk/packages/plugin-api, пока не опубликован
npm run check && npm test       # типы и чистая логика
sh tests/rpc.sh                 # методы на заглушке хоста plugin-sdk
s2p lint --official .           # граница API
s2p build . --unsigned          # .s2p
```
